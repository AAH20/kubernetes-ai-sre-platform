# Claims and limitations

This public project represents an anonymous, synthetic reference architecture.
It does not identify, describe, or claim deployment by any particular company.

- It complements an existing compliance system; it is not a certification tool.
- It does not connect to live AWS, Kubernetes, Elasticsearch, or VictoriaLogs in
  v0.1.
- The AI SRE engine computes decisions and simulates outcomes; live remediation is
  intentionally disabled.
- Test success proves deterministic behavior for the included fixture, not
  production control effectiveness.
- Evidence hashes are integrity checks, not signatures or independent validation.
- Migration parity covers only the queries, fields, streams and material
  detection scenarios explicitly tested.
- Financial values in examples are synthetic and must not appear as production
  savings or returns.
